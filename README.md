## 📖 About This Repository

This repository contains a carefully selected collection of Python projects designed to demonstrate fundamental programming concepts and best practices. Each project is:

- 🎯 **Self-contained** — Complete with all necessary files and documentation

- 🌍 **English-first** — All code, comments, and documentation in English

## 🚀 Getting Started

### Prerequisites

Ensure you have Python installed on your system:

```bash
python --version  # Should be 3.8 or higher
```

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/yoan9601/Small-Python-Projects.git
cd Small-Python-Projects
```

2. **Navigate to any project**
```bash
cd bill-calculator
```

3. **Run the project**
```bash
python main.py
```

### Project Structure


## 🎓 What You'll Learn

By completing these projects, you'll gain practical experience with:

- ✅ **Python Fundamentals** — Variables, data types, operators
- ✅ **Control Flow** — If/else statements, loops, logic
- ✅ **Functions** — Creating reusable code blocks
- ✅ **Data Structures** — Lists, dictionaries, tuples, sets
- ✅ **String Manipulation** — Working with text data
- ✅ **File I/O** — Reading and writing files (advanced projects)
- ✅ **OOP Basics** — Classes and objects introduction
- ✅ **Error Handling** — Try/except blocks
- ✅ **Algorithms** — Searching, sorting, encryption
- ✅ **Best Practices** — Code organization, documentation, testing
- ✅ **Modular Design** — Separating concerns and importing modules
